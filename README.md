# MT564 Lens

Parse, validate and compare SWIFT MT564 corporate action messages,
and explain them in plain English. All data is synthetic.

## Why this exists
Corporate action messages are hard to read and easy to get wrong.
This project makes them easier to check, compare and understand.

## Planned features
- [ ] Synthetic MT564 message generator
- [ ] Parser (MT564 to JSON and SQLite)
- [ ] Validator (mandatory fields, date logic)
- [ ] Diff between original and replacement messages
- [ ] Plain-English summaries

## Status
Early development.
